
# Part B: User Stories and Acceptance Criteria

| User Story ID | User Story | Linked Requirement | Acceptance Criteria |
| :--- | :--- | :--- | :--- |
| **US1** | As a seller, I want item details auto-populated from photos, so that I can publish ads quickly. | FR1 | 1. Uploading 3 photos populates title and category in under 3s.<br>2. Users can manually override auto-filled values. |
| **US2** | As a buyer, I want to filter items by verified visual condition, so that I avoid damaged goods. | FR4 | 1. Filtering by "Mint" condition displays only verified items.<br>2. Clearing filters restores all listings. |
| **US3** | As a seller, I want an AI agent to respond when offline, so that I do not miss prospective buyers. | FR3 | 1. Automated answers trigger for common inquiry patterns.<br>2. All automated responses show an explicit AI badge. |
