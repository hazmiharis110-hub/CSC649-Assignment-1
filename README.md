# Agentic AI Assistant for Faster Mudah.my Listings

> CSC649 Assignment 1: a proposal for an Agentic AI assistant that helps sellers write complete ads and answers buyer questions on Mudah.my.

## Status

**Complete.** All documents for Assignment 1 are finished and ready for marking.

## Problem

Sellers on Mudah.my must fill in many form fields by hand, so many ads have missing details or a wrong price. Buyers then ask the same questions again and wait for the seller to reply. This slows down sales, and some buyers leave before they buy anything.

## Specialised Technology

**Agentic AI** (main technology). The agent uses **computer vision** as one of its tools to read the seller's photos.
